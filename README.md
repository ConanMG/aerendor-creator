# Dremaria Character Creator
Dremaria is a TTRPG created from D&D's 5.5 ruleset with modifications made in classes, species and much more to adapt it to the playstyle me and my friends enjoy. This rules weren't created with balance in mind so many things might be very op.

This project aims to create an app were you can create and manage characters for the aforementioned system. Furthermore, this project is a way for me to test my abilities with React JS after having finished an online course as well as an excuse to try Tailwind CSS which I wanted to give a whirl.
